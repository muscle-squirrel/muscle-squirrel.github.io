# 리눅스, 권한 이란?
리눅스는 여러 사용자가 하나의 시스템을 사용할 수 있는 운영체제야. 따라서 특정 파일에 누가 접근하고, 수정하고, 실행할 수 있는지 정해야 함

따라서 파일이나 디렉터리에 접근할 수 있는 사용자와
수행할 수 있는 작업을 제한하기 위해 권한(Permission)을 사용한다.

권한을 설정하는 목적은 다음과 같다.

- 허가되지 않은 사용자의 접근 방지
- 중요한 파일의 수정 및 삭제 방지
- 프로그램 실행 제한
- 시스템 보안 및 안정성 유지

## 권한 구조
User(u) : 파일의 소유자
Group(g) : 파일의 소유 그룹에 속한 사용자
Others(o) : 소유자와 소유 그룹에 해당하지 않는 사용자

```text
-   rwx   r-x   r-x
│    │     │     └── 그 외 사용자(Others)
│    │     └──────── 그룹(Group)
│    └────────────── 소유자(User)
└─────────────────── 파일 종류
```

### 3.1 파일 종류
권한 문자열의 첫 번째 문자는 파일의 종류를 의미한다.

| 기호 | 의미 |
| --- | --- |
| `-` | 일반 파일 |
| `d` | 디렉터리 |
| `l` | 심볼릭 링크 |
| `b` | 블록 장치 파일 |
| `c` | 문자 장치 파일 |
| `s` | 소켓 |
| `p` | 네임드 파이프 |

### 3.2 권한 종류
| 권한 | 영문 | 숫자 | 의미 |
| --- | --- | --- | --- |
| `r` | Read | 4 | 읽기 |
| `w` | Write | 2 | 쓰기 |
| `x` | Execute | 1 | 실행 |
| `-` | None | 0 | 권한 없음 |

### 3.3 출력 결과 해석
```text
-rwxr-xr-x  1 user user 120 Nov 24 10:00 run.sh
```

| 출력 항목 | 설명 |
| --- | --- |
| `-rwxr-xr-x` | 파일 종류 및 권한 |
| `1` | 하드 링크 개수 |
| `user` | 파일 소유자 |
| `user` | 파일 소유 그룹 |
| `120` | 파일 크기(Byte) |
| `Nov 24 10:00` | 마지막 수정 시간 |
| `run.sh` | 파일명 |

위 파일의 권한은 다음과 같다.

- 소유자: 읽기, 쓰기, 실행 가능
- 그룹: 읽기, 실행 가능
- 그 외 사용자: 읽기, 실행 가능

#### 연산자

| 기호 | 의미 |
| --- | --- |
| `+` | 권한 추가 |
| `-` | 권한 제거 |
| `=` | 권한 지정 |

#### 사용 방법

```bash
chmod [대상][연산자][권한] [파일명]
```

#### 사용 예시

| 명령어 | 설명 |
| --- | --- |
| `chmod u+x run.sh` | 소유자 실행 권한 추가 |
| `chmod g+w run.sh` | 그룹 쓰기 권한 추가 |
| `chmod o-r run.sh` | 그 외 사용자 읽기 권한 제거 |
| `chmod go-w run.sh` | 그룹과 그 외 사용자 쓰기 권한 제거 |
| `chmod a+x run.sh` | 모든 사용자 실행 권한 추가 |
| `chmod u=rw run.sh` | 소유자 권한을 읽기, 쓰기로 지정 |
| `chmod o= run.sh` | 그 외 사용자의 모든 권한 제거 |
