리눅스 서버에는 마우스가 없습니다. 모든 일을 **글자로 명령해서** 처리합니다.
이번 글에서는 그 출발점인 터미널과 셸, 그리고 "지금 어디에 있고, 어디로 갈지"를 다루는 명령어를 정리합니다.

## 터미널과 셸은 무엇이 다를까

| 이름 | 역할 | 예 |
| :--- | :--- | :--- |
| **터미널** | 글자를 입력하고 결과를 보여 주는 **창(프로그램)** | macOS 터미널, iTerm2, Windows Terminal |
| **셸** | 입력한 명령을 해석해서 **운영체제에 전달하는 프로그램** | `bash`, `zsh`, `sh` |

터미널은 화면이고, 셸은 그 안에서 실제로 명령을 알아듣는 통역사입니다.
지금 쓰고 있는 셸은 이렇게 확인할 수 있습니다.

```console
$ echo $SHELL
/bin/bash
```

> 프롬프트 끝의 기호로 권한을 구분할 수 있습니다. `$`는 일반 사용자, `#`는 **root**입니다.
{: .prompt-info }

## 손이 편해지는 세 가지

### Tab 자동완성

명령어나 파일 이름을 앞 글자만 치고 <kbd>Tab</kbd>을 누르면 나머지를 채워 줍니다.
후보가 여러 개면 <kbd>Tab</kbd>을 두 번 눌러 목록을 봅니다.

```console
$ cd Doc<Tab>        →  cd Documents/
```

오타를 줄이는 가장 쉬운 방법이라, 습관이 되면 타이핑 양이 절반으로 줄어듭니다.

### history

지금까지 입력한 명령이 번호와 함께 저장되어 있습니다.

```console
$ history
  101  cd ~/project
  102  ls -al
  103  pwd
$ !102               # 102번 명령을 다시 실행
```

<kbd>↑</kbd> <kbd>↓</kbd>로 이전 명령을 불러오고, <kbd>Ctrl</kbd> + <kbd>R</kbd>로 과거 명령을 검색할 수 있습니다.

### clear

화면을 깨끗하게 지웁니다. 단축키는 <kbd>Ctrl</kbd> + <kbd>L</kbd>입니다.

## 지금 어디에 있지? — `pwd`

**p**rint **w**orking **d**irectory. 현재 위치를 보여 줍니다.

```console
$ pwd
/home/hyeonjong
```

## 무엇이 있지? — `ls`

| 명령 | 보여 주는 것 |
| :--- | :--- |
| `ls` | 파일과 폴더 이름만 |
| `ls -l` | 권한, 소유자, 크기, 수정 시각까지 **자세히** |
| `ls -al` | 위 내용 + `.`으로 시작하는 **숨김 파일까지** |

```console
$ ls -al
drwxr-xr-x  5 hyeonjong hyeonjong 4096 Nov 18 19:00 .
drwxr-xr-x  3 root      root      4096 Nov 10 09:12 ..
-rw-r--r--  1 hyeonjong hyeonjong  220 Nov 10 09:12 .bashrc
drwxr-xr-x  2 hyeonjong hyeonjong 4096 Nov 18 18:40 project
```

맨 앞 글자가 `d`면 디렉터리, `-`면 일반 파일입니다.
나머지 `rwxr-xr-x`는 **권한**인데, 파트 3에서 자세히 읽어 봅니다.

## 어디로 갈까? — `cd`

| 명령 | 이동하는 곳 |
| :--- | :--- |
| `cd 폴더` | 해당 폴더로 |
| `cd ~` 또는 `cd` | 내 **홈 디렉터리**로 |
| `cd ..` | 한 단계 **위** 폴더로 |
| `cd -` | **바로 전에 있던** 폴더로 |

```console
$ pwd
/home/hyeonjong
$ cd project
$ cd ..
$ cd /var/log
$ cd -               # 직전 위치로 되돌아가기
/home/hyeonjong
```

> `.`은 **현재 폴더**, `..`은 **상위 폴더**를 뜻합니다. `ls -al` 결과 맨 위 두 줄이 바로 이것입니다.
{: .prompt-tip }

## 절대 경로와 상대 경로

같은 폴더도 두 가지 방법으로 가리킬 수 있습니다.

| 구분 | 기준 | 생김새 | 예 |
| :--- | :--- | :--- | :--- |
| **절대 경로** | 최상위 `/` | 항상 `/`로 시작 | `/home/hyeonjong/project` |
| **상대 경로** | **현재 위치** | `/` 없이 시작 | `project`, `../hyeonsu` |

```console
$ pwd
/home/hyeonjong

$ cd /home/hyeonjong/project   # 절대 경로: 어디서 실행해도 같은 곳
$ cd ../../hyeonsu             # 상대 경로: 지금 위치에 따라 결과가 달라짐
$ pwd
/home/hyeonsu
```

> 스크립트나 설정 파일에 경로를 적을 때는 **절대 경로**가 안전합니다.
> 상대 경로는 실행하는 위치가 바뀌면 엉뚱한 파일을 가리킬 수 있습니다.
{: .prompt-warning }

## 실습 과제

- [ ] `echo $SHELL`로 내가 쓰는 셸 확인하기
- [ ] 홈 디렉터리에서 `ls -l`과 `ls -al`의 차이 비교하기
- [ ] `cd /var/log` → `cd -` → `cd ..` 순서로 이동하며 매번 `pwd` 확인하기
- [ ] 같은 폴더를 절대 경로와 상대 경로로 각각 찾아가 보기
- [ ] `history`에서 번호로 이전 명령 다시 실행해 보기
