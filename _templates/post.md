# 파일명, 제목 규칙
헤더의 title은 사이트에서 보이는 이름입니다. 글의 주제가 잘 드러나도록 작성해주세요.  
파일명 규칙은 다음과 같습니다. `주차-파트-종류(note/quiz/practice).md`  
예를 들어, 1주차 파트3의 개념 정리 글이라면 `w1-p3-note.md`입니다.  

# 이미지 삽입
포스트에 이미지를 삽입할 땐 아래와 같이 삽입합니다.
```markdown
![이미지 설명](이미지 위치)
```
이미지 설명은 이미지 로드가 불가능한 경우 대신 보여주는 글자입니다.  
이미지 위치는 이미지를 직접 업로드하는지, 웹의 이미지를 불러오는지에 따라 방법이 바뀝니다.
## 이미지 직접 업로드
1. 삽입할 이미지를 레포의 `/assets/img/이름/`아래에 저장합니다.
2. 이미지 위치에 `/assets/img/이름/파일명.확장자`를 넣습니다.
## 웹 이미지 삽입
1. 이미지 위치에 웹 이미지 링크를 넣습니다. `ex. https://example.com/docker-arch.png`

# 코드/명령어 작성
코드나 명령어를 작성하는 경우 코드블럭 혹은 인라인 코드를 이용합니다.  
문장 안에 짧은 코드를 작성하는 경우 백틱(`)을 코드 앞 뒤로 감쌉니다.  
긴 코드, 여러 줄의 코드를 작성하는 경우 백틱 3개를 코드 윗줄, 아랫줄에 감쌉니다. 윗줄의 백틱의 경우엔, 백틱 3개 뒤에 어떤 언어인지 붙여 하이라이트를 적용합니다. (python, bash 등)
